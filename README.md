# Omnili — Fengmin 的个人作品集

个人刊物式作品集网站：实时协作、AI Agent、数据可视化——把想法做成产品。

## 技术栈

- [Next.js 16](https://nextjs.org/)（App Router）
- React 19
- TypeScript
- Tailwind CSS v4

## 设计理念

Editorial Studio 刊物风——纸白、墨黑、克莱因蓝三色系统，衬线大标题与
编号目录式导航，像一本可以翻阅的个人杂志。

## 本地开发

```bash
npm install
npm run dev
```

访问 http://localhost:3000

## 构建与部署

```bash
npm run build
```

推荐部署到 [Vercel](https://vercel.com/)，零配置即可上线。
